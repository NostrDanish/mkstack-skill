# mkstack-skill

Scaffold a Nostr web client from
[soapbox-pub/mkstack](https://gitlab.com/soapbox-pub/mkstack) and build it
with OpenCode.

Depends on [opencode-skill](https://github.com/NostrDanish/opencode-skill).
This repo does not repeat OpenCode install/config.

## Install

Copy or symlink into the agent's skills directory alongside `opencode`.
